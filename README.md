## 核心演算法與架構

本程式以 C 語言撰寫，核心採用 **定式棋譜比對（Opening Book / Pattern Matching）** 結合 **啟發式棋型權重評估（Heuristic Position Evaluation）**：

### 1. 特殊開局與殘局資料庫 (`chess.h` & `check()`)

* 預先儲存了多組關鍵棋譜盤面陣列 `chess[9][19][20]`。


* 每回合優先透過 `check()` 快速比對是否符合預設盤面；一旦匹配成功，立即精準回應預設的最佳解落子位置（如開局定式或必殺手），以極高效率省下運算資源並規避早期失誤。



### 2. 八方向棋型權重評估 (`weight()`)

當盤面脫離預設棋譜時，程式遍歷所有未落子的空位（`.`），沿著水平、垂直與兩條對角線等 **4 個主方向（雙向延伸共 8 方向）** 評估連續同色棋子數與兩側活口（`hole`）：

| 棋型類別 | 條件特徵 | 權重分數 |
| --- | --- | --- |
| **五連 / 連五** | 連續 5 顆以上 | `10,000,000`（必勝點）

 |
| **活四** | 連續 4 顆且雙向活口 (`hole == 2`) | `500,000`<br> |
| **衝四** | 連續 4 顆且單向活口 (`hole == 1`) | `100,000`<br> |
| **活三** | 連續 3 顆且雙向活口 (`hole == 2`) | `5,000`<br> |
| **眠三** | 連續 3 顆且單向活口 (`hole == 1`) | `500`<br> |
| **活二** | 連續 2 顆且雙向活口 (`hole == 2`) | `100`<br> |
| **眠二** | 連續 2 顆且單向活口 (`hole == 1`) | `50`<br> |

### 3. 動態攻守決策公式 (`main.c`)

程式對每一個空格計算我方攻擊分（`myScore`）與敵方防守分（`oppScore`），並依局勢採用動態加權：

* **絕殺局面**：若我方存在勝勢點（`myScore >= 10,000,000`），採取強攻策略：

$$\text{Score} = 2 \times \text{myScore} + \text{oppScore}$$



* **常規對局**：進攻略微優先於防守（1.3 比 1 比例），兼顧封堵對方威脅與己方做棋拓展：

$$\text{Score} = 1.3 \times \text{myScore} + \text{oppScore}$$



* **天元首手**：若盤面全空（先手執黑），自動落子於天元中心點 `I, 9` 掌握主動權。

## 專案結構

```text
├── Makefile        # 編譯設定檔，可直接生成 cej112016 執行檔
├── README.md       # 專案介紹文件
├── chess.h         # 預設棋譜與開局特徵矩陣，防範程式漏洞、根據對手打擊弱點
├── function.h      # 評估函式與檢查模組介面宣告
├── function.c      # 對於可落棋點評分(8方位判斷)
└── main.c          # 主流程：輸入解析、綜合評分最大化選點與落子決策

```

## 編譯與執行

使用專案內建的 `Makefile` 即可快速編譯：

```bash
make

```

執行程式時傳入所屬執棋顏色（`Black` 或 `White`），並透過標準輸入傳入 19x19 棋盤字串：

```bash
./cej112016 Black < board_state.txt

```
