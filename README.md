## 核心設計與技術亮點

* **輕量級高效架構 (Pure C)**：完全基於原生 C 語言開發，無外部重型函式庫依賴，大幅降低記憶體與 CPU 資源開銷，確保毫秒級低延遲決策。
* **二維棋盤狀態管理**：以二維陣列（2D Array）即時記錄 $15 \times 15$ 盤面落子狀態，落子更新與勝負判定具備 $O(1)$ 局部更新效率。
* **對稱性空間走訪優化**：針對棋盤連續棋型特徵，將全方向檢查精簡為空間對稱的 4 方向掃描（橫向、縱向、兩條對角線），直接減少 50% 冗餘走訪運算量。
* **啟發式權重決策機制 (Rule-based Heuristic)**：
  * 即時偵測「連五」、「活四」、「死四」、「活三」等核心威脅棋型。
  * 針對攻守狀態設定動態權重，優先阻斷對手關鍵連線（如衝四、活三），兼顧防禦穩固度與進攻連貫性。
